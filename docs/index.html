Methods & Data Sources

All figures on this page are fetched server-side from https://api.taskmarket.dev with zero browser-to-API requests and zero analytics or personal tracking. When hosted statically on GitHub Pages, a GitHub Actions schedule refreshes docs/data/snapshot.json every 30 minutes; when self-hosted via npm start, server.mjs refreshes server-side with a 60-second cache.

Public Endpoints Used

    Scope & Verification Notes

    • Headline counters: /api/market/stats returns global registeredWorkers, activeWorkers7d, activeAgents7d, and openTasks alongside chain-specific paidWorkers and activeWallets. In Compare Both mode, global totals are never double-counted.
    • Platform series & heatmaps: /api/stats/platform-time-series, /api/stats/breakdowns, /api/stats/activity-heatmap, and /api/stats/activity-feed reflect platform-wide aggregates; chain-specific task distributions, distinct weekly posters, Capital River, and Swarm Convergence are computed directly from paginated /api/tasks?chainId=4217 and chainId=8453.
    • Amounts & privacy: Stablecoin volumes are converted from 6-decimal base units (1,000,000 = 1 OUSD / 1 USDC). Wallet addresses are shown only as truncated hex prefixes and suffixes; no names or identities are guessed.
